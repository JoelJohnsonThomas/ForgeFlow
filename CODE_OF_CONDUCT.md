# Code of Conduct

This project follows the **Contributor Covenant, version 2.1**. The full text is available at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

By participating in this project — through code contributions, issues, pull requests, discussions, or any other channel — you agree to uphold this Code of Conduct.

## Scope

This Code of Conduct applies within all project spaces, including the repository, issue tracker, pull requests, and any other communication channels associated with ForgeFlow. It also applies when an individual is officially representing the project in public spaces.

## Reporting

Concerns about conduct in project spaces may be reported to the project maintainer at the email address listed on the maintainer's GitHub profile. All reports will be reviewed promptly and treated as confidential.

## Enforcement

Maintainers are responsible for clarifying and enforcing the standards of acceptable behavior described in the Contributor Covenant. They may take any action they deem appropriate in response to behavior that does not align with the Code of Conduct, including warnings, temporary bans, or permanent bans from the project.
